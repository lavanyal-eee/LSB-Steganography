# LSB Image Steganography Using C

## Project Overview
A C-based project that hides secret text inside a BMP image using the Least Significant Bit (LSB) technique and extracts it through decoding.

## Features
- Hide secret text inside BMP images.
- Extract hidden text from encoded images.
- Validate input files.
- Check image capacity before encoding.

## Technologies Used
- C Programming
- File Handling
- Bitwise Operations
- LSB Steganography
